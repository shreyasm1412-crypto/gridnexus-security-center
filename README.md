# GridNexus Security Center

Build a complete, polished frontend-only web application named **GridNexus AI**.

## STRICT SCOPE — FOLLOW EXACTLY

Build ONLY the UI specified below.

Do NOT add:

* extra pages
* extra dashboard widgets
* chatbots
* unnecessary settings pages
* billing pages
* user management pages
* authentication backend
* real machine learning
* real cybersecurity tools
* external APIs
* unnecessary features

Use realistic mock data only.

The application represents a **software-based AI cybersecurity monitoring and threat response system for a simulated smart grid**.

The purpose is to demonstrate:

**Normal Grid Monitoring → Cyberattack Simulation → Threat Detection → AI Analysis → Risk Assessment → Incident Response**

This complete flow must be visually clear.

# 1. VISUAL DESIGN

Create a premium enterprise **Smart Grid Security Operations Center (SOC)** interface.

### Style:

* Dark professional dashboard
* Deep charcoal/near-black background
* Subtle blue and cyan energy highlights
* Red used ONLY for critical threats
* Amber/yellow used ONLY for warnings
* Green used ONLY for normal/safe status
* Clean white/light-gray text
* Thin borders
* Moderate rounded corners
* Soft shadows
* Subtle glow on active status indicators

Do NOT use:

* excessive gradients
* excessive neon effects
* oversized cards
* cartoon illustrations
* excessive animations
* cluttered layouts

The design should look like a **real enterprise cybersecurity platform**, not a student project.

### Typography:

Use a clean modern sans-serif font.

Hierarchy:

* Page titles: bold and prominent
* Section headings: medium-large
* Metrics: large numbers
* Labels: small and subtle

Maintain generous spacing and consistent alignment.
